サンプルガイド

このページは docs/guides/ に置かれた自己完結 HTML の実装例です。 独自の CSS と JS を持ち、ダッシュボード本体と衝突しません。 新しいガイドを作るときのリファレンスとして使ってください。

1. テーマ連携

現在のテーマ: light。 サイドバーのダークモード切替に追随します（URL クエリ ?theme= で初期化し、 postMessage で切替通知を受け取る）。

2. 独自 JS による可視化

バーをクリックすると値がランダムに変わります。D3 等を使う場合は assets/ に vendor してください。

3. 高さ通知

このガイドは guide-height メッセージで自身の高さをホストに伝えているため、 iframe 内スクロールが発生しません。
